# Change Logs

## v0.1.0

 - circular editor: selected stop gets an outline; the two end stops can't be removed; the swatch next to the color code opens ldcolorpicker
 - add / remove / apply buttons are line icons, vertically centered
 - events: `change`, `select`, `apply`, `tap`
 - new `GradientEditor.Bar`: linear bar editor ( click the bar to add a stop, drag to move, double-click to change color )
 - utilities: `css`, `svg`, `color-at`, `css-angle`
